## Featured Project

### [BuildIMS](https://github.com/anascs12/builtIMS)
**The student developer platform for IMSciences Peshawar.** Students use it to ship projects, keep a daily coding streak,
team up on ideas and compete in showdowns judged by faculty.

- Project showcase with faculty approval and voting
- Daily challenges, streaks and leaderboards
- Idea Garage, Showdowns and a Skills Gap Radar
- React + Vite frontend, Node.js + Express API, PostgreSQL, Redis, Socket.io, and Docker for one-command setup

*Role: Co-Lead Developer, working with [Anas Khan](https://github.com/anascs12)*
